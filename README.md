# Speldesign för nybörjare

Projekt för en svensk teoretisk lärobok om speldesign, med genreöversikter och konkreta workshopövningar.

## Struktur
- `docs/` innehåller bokspecifikation, kapitelplan, canon, terminologi, status och exportmetadata.
- `chapters/` innehåller inledning och kapitel.
- `exercises/` innehåller samlade övningar.
- `assets/` innehåller omslag, bildpromptar och framtida illustrationer.
- `exports/` är avsedd för EPUB/PDF/DOCX/Markdown-export.

## Nuvarande status
Projektet innehåller inledning samt kapitel 1–8.
