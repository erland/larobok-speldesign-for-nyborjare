# Övningar till kapitel 3: Kärnloopen

## Övning 1: Hitta kärnloopen

Välj ett enkelt spel och fyll i:

| Fråga | Svar |
|---|---|
| Vad gör spelaren oftast? | |
| Hur svarar spelet? | |
| Vad får spelaren som belöning eller ny information? | |
| Varför vill spelaren fortsätta? | |
| Hur snabbt upprepas loopen? | |

Skriv sedan spelets kärnloop i fyra till sex steg.

## Övning 2: Tre loopar för samma tema

Tema: en övergiven ruin i en skog.

Skriv en kärnloop för varje variant:

1. Pusselspel
2. Actionspel
3. Strategiskt utforskningsspel

Jämför vilka handlingar, responser och belöningar som skiljer sig.

## Övning 3: Loopen som hypotes

Fyll i mallen:

> Om spelaren får göra [handling], får [respons] och belönas med [belöning], då kommer spelaren vilja [fortsättning].

Beskriv sedan en minimal prototyp som skulle kunna testa hypotesen.

## Reflektionsfråga

Vilken del av din loop är svagast just nu: handlingen, responsen, belöningen eller skälet att fortsätta? Varför?
