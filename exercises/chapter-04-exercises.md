# Övningar till kapitel 4: Regler, resurser och begränsningar

## Syfte

Övningarna hjälper dig att analysera hur regler, resurser och begränsningar skapar val. Använd gärna ett enkelt spel du själv har byggt eller kopierat som utgångspunkt.

## Övning 1: Regelkarta

Välj en mekanik, till exempel hoppa, skjuta, samla, bygga, öppna eller prata.

Fyll i:

| Fråga | Svar |
|---|---|
| Vad gör spelaren? | |
| Vilken regel styr handlingen? | |
| Vad händer om handlingen lyckas? | |
| Vad händer om handlingen misslyckas? | |
| Finns kostnad, risk eller konsekvens? | |
| Hur får spelaren feedback? | |

## Övning 2: Resurs med två användningar

Skapa en resurs som kan användas på två olika sätt. Resursen ska tvinga spelaren att välja mellan kortsiktig nytta och framtida möjlighet.

Exempel:

- fackla: lysa upp ett rum eller skrämma bort en fiende
- energi: använda specialförmåga eller spara till försvar
- information: avslöja en genväg eller förhandla med en figur

Beskriv:

1. Resursens namn.
2. Hur spelaren får resursen.
3. Första användningen.
4. Andra användningen.
5. Vilket val resursen skapar.
6. Vilken känsla valet ska ge spelaren.

## Övning 3: Begränsningsanalys

Välj en begränsning från ett spel du känner till.

Besvara:

1. Vad hindrar begränsningen spelaren från att göra?
2. Vilket val skapar begränsningen?
3. Vilken upplevelse stödjer den?
4. När blir den rolig, spännande eller strategisk?
5. När riskerar den att bli irriterande?

## Fördjupning: Designa tre versioner

Utgå från samma grundidé: spelaren vill ta sig genom en låst ruin.

Skapa tre versioner:

1. En version med nästan inga begränsningar.
2. En version med en tydlig resurs.
3. En version där samma resurs kan användas på två sätt.

Jämför versionerna:

| Version | Styrka | Svaghet | Vilken upplevelse skapar den? |
|---|---|---|---|
| Nästan inga begränsningar | | | |
| En tydlig resurs | | | |
| Resurs med två användningar | | | |

## Kontrollfrågor

1. Är varje regel begriplig för spelaren?
2. Finns det minst ett val där spelaren måste prioritera?
3. Har valet kostnad, risk eller konsekvens?
4. Får spelaren tillräcklig information för att känna ansvar för beslutet?
5. Stödjer begränsningen spelets tänkta upplevelse?
